# Desafio WebDev — ViaCEP & Lógica de Programação

Este repositório foi criado como resposta a um desafio técnico. Ele contém:

1. Uma **aplicação web** que consome a API [ViaCEP](https://viacep.com.br/) para consultar endereços com base no CEP.
2. Uma série de **exercícios de lógica** na pasta `parteUm`, resolvidos com JavaScript.

## Parte 1 – Exercícios de Lógica (`parteUm/`)

- Scripts desenvolvidos em JavaScript puro
- Propostas comuns de lógica para fixar estrutura de repetição, condicionais, arrays e funções
- Todos os exercícios estão comentados e organizados em um único arquivo `.js`

---

## Parte 2 – Consulta de CEP com API ViaCEP

A aplicação recebe um **CEP digitado pelo usuário**, consulta a API ViaCEP e exibe as informações retornadas em tempo real na interface.

### Funcionalidades

- Validação básica de CEP
- Requisição HTTP com `fetch()`
- Renderização dinâmica dos dados retornados pela API
- Layout simples com HTML e CSS puro
